hoga:Student → Book Request → Librarian Approve → Issue Book → Student Book Receive → Return BookJab student book wapas karega:Librarian Return Books page kholega.Usko issued books ki list milegi.Librarian jis student ki book return hui hai usko select karega.Return button press karega.System:Issue record ko returned mark karega.Return Book record create karega.Book ki available quantity +1 karega.Student ki issued-book count update karega.Agar book late return hui hai to system automatically Fine calculate karega.Student ko notification milegi:"Your book has been returned successfully."Agar fine laga hai:"A fine of Rs. ___ has been generated for late return."| Step   | کام                                        | کون سی files
